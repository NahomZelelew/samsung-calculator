# Samsung Calculator Replica

A fully functional, modern web replica of the Samsung One UI Calculator app interface. Built step-by-step to practice vanilla JavaScript DOM manipulation, state tracking, and clean CSS UI layouts.

## ✨ Features

- **Standard Layout:** Replicates the clean button grid and color accents of Samsung One UI.
- **Smart Brackets:** Intelligently chooses to open `(` or close `)` based on calculation context.
- **Active Operator Highlight:** Highlights the current active operator (`+`, `-`, `×`, `÷`) when clicked.
- **Auto-Scaling Screen:** Automatically scales text sizes downward to handle longer mathematical string formulas cleanly.
- **Smart Reset:** Clears previous inputs gracefully when entering a new number right after evaluation while keeping operators chained.

## 🚀 Technologies Used

- HTML5
- CSS3 (Flexbox, Transitions, Clamped Typography)
- JavaScript (Vanilla ES6+)
